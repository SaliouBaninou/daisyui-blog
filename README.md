# 🚀 Blog List avec NewsAPI 🎉

Ce projet est une application React affichant une liste d'articles de blog en utilisant l'API [NewsAPI](https://newsapi.org/). Chaque article est présenté sous forme de carte (card) et redirige vers l'article original lorsqu'on clique dessus. 📖✨

## 🛠️ Technologies utilisées

- **React.js** ⚛️ - Framework JavaScript pour la création d'interfaces utilisateur.
- **DaisyUI** 🎨 - Composants Tailwind CSS pour un design moderne et réactif.
- **NewsAPI** 📰 - API permettant de récupérer des articles d'actualités.

## 🚀 Installation

1. **Cloner le projet** 🖥️

   ```bash
   git clone https://github.com/SaliouBaninou/daisyui-blog.git
   cd daisyui-blog
   ```

2. **Installer les dépendances** 📦

   ```bash
   npm install
   ```

3. **Démarrer le serveur local** 🔥

   ```bash
   npm run dev
   ```

## 🎯 Fonctionnalités

- 💡 Affichage dynamique des articles de blog récupérés depuis NewsAPI.
- 🎨 Design moderne et responsive grâce à DaisyUI et Tailwind CSS.
- 🌍 Redirection vers l'article original en un clic.
